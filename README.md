##  Cómo compilar y ejecutar en Visual Studio
> **Importante:** Este es un proyecto basado en **CMake**, por lo que debe abrirse como **Carpeta** y no como archivo `.sln`.

1. Clonar o descargar este repositorio (si se descargó en `.zip`, descomprimir la carpeta).
2. Abrir **Visual Studio 2022** y en la ventana de inicio hacer clic en **"Abrir una carpeta local"** (*Open a local folder*), o ir a **Archivo -> Abrir -> Carpeta...**
3. Seleccionar la carpeta raíz del proyecto (`Tetris-master`, donde se encuentra el archivo `CMakeLists.txt`).
4. **Esperar unos segundos** a que la consola inferior de salida indique que la configuración de CMake ha finalizado (descargará e integrará `raylib` automáticamente).
5. En la barra superior, desplegar la flecha junto al botón verde de inicio, seleccionar **`Tetris.exe`** y presionar **F5** (o hacer clic en el botón verde de Play).
